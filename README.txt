DASHBOARD PELAYANAN - STARTER FRONTEND

1. Buat project Vite React:
   npm create vite@latest frontend -- --template react
   cd frontend
   npm install

2. Install dependency:
   npm install recharts lucide-react axios
   npm install xlsx jspdf jspdf-autotable

3. Salin folder src dari paket ini ke folder frontend/src
   (boleh mengganti file src yang dibuat Vite).

4. Jalankan:
   npm run dev

CATATAN:
- Tampilan saat ini memakai data contoh/ilustrasi, belum terhubung ke Google Spreadsheet.
- Angka statistik dan grafik perlu disesuaikan lagi setelah integrasi dan validasi data.
- Jangan masukkan kredensial Google/API key ke frontend atau unggah file .env ke GitHub.
